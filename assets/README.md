# Offline map assets

- Leaflet 1.9.4 JS/CSS: https://unpkg.com/leaflet@1.9.4/dist/ — BSD-2-Clause; see LEAFLET-LICENSE.
- jQuery 3.7.1: https://code.jquery.com/jquery-3.7.1.min.js — MIT; see JQUERY-LICENSE.
- Natural Earth 1:110m land polygons: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson — public domain, https://www.naturalearthdata.com/about/terms-of-use/.

Land outlines are generalized for overview maps, not boundary or navigation data. Circle markers do not need Leaflet's external marker images. OSM online tiles are optional and retain their attribution.
